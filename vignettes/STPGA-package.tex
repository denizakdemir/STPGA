\section{Introduction}\label{introduction}

The \textbf{STPGA} (Subset Training Population Genetic Algorithm)
package provides advanced tools for optimizing training set selection in
genomic prediction and experimental design. This vignette demonstrates
the package's key functionalities using real wheat genomic data.

\subsection{Key Features}\label{key-features}

\begin{itemize}
\tightlist
\item
  \textbf{Modern optimization criteria}: A-, D-, E-optimality, PEV,
  Cook's Distance
\item
  \textbf{Mixed model support}: BLUP-based criteria for genomic
  selection
\item
  \textbf{Genetic algorithms}: Single and multi-objective optimization
\item
  \textbf{Flexible interface}: Unified criterion function with legacy
  compatibility
\item
  \textbf{Robust numerics}: Ridge regularization and numerical stability
\end{itemize}

The latest version includes significant improvements to the genetic
algorithm implementation:

\begin{itemize}
\tightlist
\item
  \textbf{Multi-criteria convergence detection}: Monitors fitness
  stabilization, improvement rate, population diversity, and fitness
  variance
\item
  \textbf{Restart mechanisms}: Automatically restarts with diversified
  populations when premature convergence is detected
\item
  \textbf{Advanced selection methods}: Tournament, elite, rank-based,
  and hybrid selection with validation
\item
  \textbf{Configurable convergence windows}: Flexible convergence
  tracking with diagnostic tools

\section{Conclusion}\label{conclusion}

The STPGA package provides a comprehensive toolkit for optimizing
training set selection in genomic prediction and experimental design.
Key features include:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Modern API}: Clean, intuitive function names with
  comprehensive documentation
\item
  \textbf{Multiple Criteria}: Classical optimality criteria plus
  prediction-focused measures
\item
  \textbf{Mixed Models}: Support for genomic selection with kinship
  matrices
\item
  \textbf{Genetic Algorithms}: Efficient single and multi-objective
  optimization
\item
  \textbf{Numerical Stability}: Ridge regularization and robust matrix
  operations
\item
  \textbf{Flexibility}: Unified interface with legacy compatibility
\end{enumerate}

\subsection{Best Practices}\label{best-practices}

\subsubsection{Criterion Selection}\label{criterion-selection}

\begin{itemize}
\tightlist
\item
  Use \texttt{pev\_mean\_normalized} for general prediction accuracy
  optimization
\item
  Consider \texttt{pev\_mean\_mm} when genetic relationships are
  available
\item
  Apply multi-objective optimization when balancing multiple criteria
\item
  Use ridge regularization (λ ≥ 1e-6) for numerical stability
\end{itemize}

\subsubsection{Training Set Size}\label{training-set-size}

\begin{itemize}
\tightlist
\item
  Select training sets of at least 30-50\% of the candidate pool
\item
  For genomic selection, aim for training sets ≥ 100 individuals when
  possible
\item
  Balance computational cost with prediction accuracy
\end{itemize}

\subsubsection{Genetic Algorithm
Configuration}\label{genetic-algorithm-configuration}

\begin{itemize}
\tightlist
\item
  \textbf{Selection Methods}:

  \begin{itemize}
  \tightlist
  \item
    Use \texttt{"tournament"} for balanced exploration/exploitation
  \item
    Use \texttt{"rank"} with \texttt{selection\_pressure\ =\ 1.2-1.8}
    for controlled selection pressure
  \item
    Use \texttt{"hybrid"} for combining multiple selection strategies
  \end{itemize}
\item
  \textbf{Convergence Settings}:

  \begin{itemize}
  \tightlist
  \item
    Set \texttt{convergence\_window\_multiplier\ =\ 3-5} for robust
    convergence detection
  \item
    Enable restart with \texttt{enable\_restart\ =\ TRUE} and
    \texttt{restart\_threshold\ =\ 0.5-0.7}
  \item
    Use \texttt{max\_restarts\ =\ 1-2} to avoid excessive computation
  \end{itemize}
\item
  \textbf{Population Parameters}:

  \begin{itemize}
  \tightlist
  \item
    Use population sizes of 50-200 for most problems
  \item
    Set \texttt{niterations\ =\ 100-500} depending on problem complexity
  \item
    Monitor convergence diagnostics to adjust parameters
  \end{itemize}
\end{itemize}

\subsubsection{Validation and
Diagnostics}\label{validation-and-diagnostics}

\begin{itemize}
\tightlist
\item
  Always check convergence diagnostics with
  \texttt{convergence\_diagnostics()}
\item
  Use cross-validation or independent test sets to validate results
\item
  Monitor restart history to detect optimization difficulties
\item
  Adjust parameters based on convergence recommendations
\end{itemize}
